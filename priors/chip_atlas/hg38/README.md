# ChIP-Atlas cache: human (hg38)

Human ChIP-Atlas TF-binding tables go here, one file per TF as `{TF}.10.tsv` (1,183
files, 988 MB). Download the priors bundle (see `../../README.md`) and extract it so the
files land here. Only needed to rebuild a human mask from scratch; precomputed masks are
loaded automatically when present.
